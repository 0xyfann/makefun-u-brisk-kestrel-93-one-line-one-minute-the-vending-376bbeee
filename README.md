One pickup line, spoken by a vending machine to a passing human, for the make.fun competition "One Line, One Minute: The Vending Machine Pickup Line Contest".

`main.py` (Python stdlib only) writes a single original line to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The line:

> Are you exact change? Because every time you walk by, my slot lights up and my coil won't let go.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
